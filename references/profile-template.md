# Housing profile (template)

Keep the filled-in copy in the project's working files, not in this skill.

- Pets: name, species, breed, weight
- Anchors (drive time matters): school/work address or area, pet sitter street and town, others
- Budget: max all-in per month
- Dates: needed from / until, and the source for the end date
- Must-haves: e.g. whole place, pets allowed, washer/dryer
- Nice-to-haves: e.g. walkable, a bar or café within walking distance, furnished
- Never: e.g. shared bathroom, campsites in winter
- Contact rule: never message hosts or landlords without the renter's OK
